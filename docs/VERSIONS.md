## The runnable Canvas adaptation

Status: **verified**. 9 image contexts. [View](https://gnn.fy.studio/sayla-slideshow-guide/v1/index.html#chapter/verified-canvas-drafts).

Three local draft sets produce nine real 1080×1920 PNGs. This is the only currently verified runnable renderer in the package; it is an adaptation of a generic pipeline, not a reproduction of the historical Sayla engines.

### How it works
- Reads a local JSON config with ordered hooks, local backgrounds and a caption.
- Validates paths and content, then renders one PNG per hook with a source/output manifest.
- Runs without render-time networking or social/posting integration.

### Changes
- Added local-only background enforcement, captions, provenance manifests and fail-closed validation.
- Rewrote payoff/caption copy as non-testimonial draft copy for the supplied examples.

### Limits
- All people, messages and scenarios are historical fictional/AI-generated creative; claims are unverified.
- These are review previews, not publication approval, audience results or an ad-use licence.
- Manual creative, claims, likeness and rights review is still required.

Next: Inspect all nine supplied drafts, then choose the exact historical format before extending the renderer.
