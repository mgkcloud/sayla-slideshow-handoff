# Scope, rights and exclusions

This is a clean public employee handoff, not a visibility flip of an internal repository. Its history starts with reviewed public files.

Included: the runnable offline factory and required sample inputs/font; sanitized historical generator/configuration snapshots; recovered copy and version notes; the public viewer; selected previews and full-resolution review downloads.

Excluded: credentials, deployment credentials/helpers, databases, account/session dumps, private chat/contact screenshots, internal source record identifiers, original-host addresses, character/reference input banks, ambiguous real-device references and uncleared rejected SlideSmith imagery. Restricted SlideSmith implementation code is not redistributed. These exclusions are not required to run the supplied local factory.

Historical snapshots are inert and may describe paid-provider workflows; their existence is not authorization to run those workflows. Unprovided dependencies and missing provenance are stated in the version notes. Full-resolution JPEG copies are re-encoded, metadata-stripped review derivatives, not byte-identical originals.

Generated actors/conversations and first-person claims are historical fiction, not proven testimonials. Publication as an employee review asset does not establish likeness or advertising-use rights. Review copy, translation, product accuracy and rights before using any asset in an ad.

The maintained factory code/schema/tests have the [MIT licence](../factory/LICENSE), matching the package declaration. Historical source snapshots, prompts, sample creative and media are explicitly outside that grant. Preserve original notices and the bundled DejaVu font licence. Third-party dependencies retain their licences. Public repository access grants no cloud credentials or owner-repository write access.
