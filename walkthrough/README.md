# Public viewer

Run `python3 -m http.server 8765 --directory walkthrough` from the repo root. No build, login or secret is needed. The Version selector reverses catalogue order and hides entries without media; individual slides remain ordered. Search/Details are optional. Source links point to this public repository or public full-resolution media.

The custom domain inherits its existing analytics; the original R2 origin remains an alternative. The local viewer itself performs GETs only. Deployment is owner-managed; no owner credentials are included.
